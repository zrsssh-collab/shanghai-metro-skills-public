# Shanghai Metro Weekly Report Template

Use this compact template for a leadership-ready weekly report. Keep only the sections needed for the case and preserve the exact statistical口径.

## 专题标题

[线路/路段/场景] + [问题或优化主题]

## 1. 问题描述/问题背景

- **时间与范围：** [reporting period, line, section/station, direction]
- **现象或风险：** [user感知, KPI异常, complaint, or capacity/coverage risk]
- **关键对象：** [exact cell/site/neighbor names and IDs]

## 2. 问题分析/排查情况

- **事实数据：** [before-state values, denominator, time window, source]
- **定位结论：** [evidence-backed cause or current best explanation]
- **影响链路：** [radio/mobility/transport/service impact, only where supported]
- **数据缺口或口径限制：** [mismatched windows, missing counters, unresolved naming]

## 3. 优化措施及效果/优化进展

1. **已实施动作：** [parameter, RF, expansion, load balancing, repair, construction, or signaling action]
2. **效果对比：** [before → after, absolute delta or percentage-point change, same-condition note]
3. **当前状态：** [closed, improved, partial, pending maintenance/construction, or not yet verified]

## 4. 后续计划

1. **下一步动作：** [specific task and responsible team]
2. **完成条件：** [date/trigger, if known]
3. **验证指标：** [PRB, users, RSRP/SINR/CQI, TCP retransmission, video pauses, handover/VoNR, etc.]

**总结句：** [One concise sentence stating the current result and remaining risk.]

## Quality checks

- Do not mix different busy periods, rounds, denominators, or metric definitions without labeling them.
- Replace vague section numbers with actual section names when verified.
- Keep confirmed facts separate from interpretation and planned work.
- Mask IMSI, MSISDN, and other personal identifiers.
