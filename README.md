# Shanghai Metro Skills

Two reusable skills for Shanghai metro wireless-network analysis and reporting:

- **shanghai-metro-complaint-analysis**: evidence-backed complaint analysis, covering PS/user-plane, KPI/KQI, SPD, radio conditions, mobility, uplink, TCP/DNS, root-cause confidence, and corrective actions.
- **shanghai-metro-weekly-report**: concise weekly reports with problem context, analysis, optimization actions and effects, remaining risks, and next steps.

Each skill contains a `SKILL.md`, interface metadata, and a separate report template. Supply your own authorized inputs and specify the reporting period and scope.

This public version contains generic instructions and templates only. It does not include source complaint records, subscriber data, real-case filenames, cell identifiers, or private project history.
